# Анализ банковских транзакций

Проект предназначен для анализа банковских транзакций из Excel-файла.

Приложение позволяет:

- анализировать расходы
- формировать отчеты
- выполнять поиск по транзакциям
- рассчитывать накопления в инвесткопилке
- генерировать JSON-ответы для веб-страниц

## Установка

Клонировать репозиторий:
git clone <repo>

Установить зависимости:
poetry install

---

## Запуск программы
python -m src.main

---

## Запуск тестов
pytest

Проверка покрытия:
pytest --cov=src
