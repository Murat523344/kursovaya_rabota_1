# Анализ банковских транзакций

Проект предназначен для анализа банковских транзакций из Excel-файла. Приложение генерирует JSON-данные для веб-страниц, формирует отчеты и предоставляет различные сервисы для анализа расходов.

## 🚀 Возможности

### Веб-страницы
- **Главная страница** - приветствие, информация по картам, топ-5 транзакций, курсы валют и цены акций
- **Страница событий** - анализ расходов и доходов по категориям

### Сервисы
- **Инвесткопилка** - расчет накоплений через округление трат
- **Выгодные категории кешбэка** - анализ категорий для максимального кешбэка

### Отчеты
- **Траты по категории** - анализ расходов за последние 3 месяца
- **Траты по дням недели** - средние траты по дням
- **Траты в рабочие/выходные дни** - сравнение расходов

## 🔧 Установка

### Требования
- Python 3.11 или выше
- Poetry (менеджер зависимостей)

### Шаги по установке

1. **Клонируйте репозиторий**
```bash
git clone https://github.com/Murat523344/kursovaya_rabota_1.git
cd kursovaya_rabota_1
```

2. **Установите зависимости через Poetry**
```bash
poetry install
```

3. **Активируйте виртуальное окружение**
```bash
poetry shell
```

4. **Настройте переменные окружения**
```bash
cp .env_template .env
# Отредактируйте .env, добавив реальные ключи API
```

5. **Добавьте файл с данными**
Поместите файл `operations.xlsx` в папку `data/`
